# Quatt Chill

> [!NOTE]
> Built on the reverse-engineered Quatt mobile API — see [About reverse-engineered features](../README.md#about-reverse-engineered-features).

Quatt Chill devices are added automatically when they are present on your installation and the [Remote Mobile API](remote-mobile-api.md) is enabled on your CIC. See [Enabling the Remote Mobile API](remote-mobile-api.md#enabling).

## Features

- **Climate control**: A climate entity for Quatt Chill devices with heating, cooling, target temperature and fan mode control.
- **Status and diagnostics**: Chill mode, fan mode, ambient temperature, status and update-state sensors.
- **Device names**: Names from the Quatt app are synchronized on refresh. Names you set manually in Home Assistant remain unchanged.
